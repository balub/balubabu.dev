# The Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current Lab experiment grid with an image-first, maintainable workshop journal, monthly workbench archive, and milestone timeline.

**Architecture:** Keep the existing Pages Router route and site shell. Store all Lab content in `src/data/lab.js`, expose pure date-ordering helpers for testable automatic chronology, and compose focused presentational components in `src/pages/lab.jsx`. Use local documentary placeholder photographs under `public/images/lab/` and Next.js `Image` for responsive rendering.

**Tech Stack:** Next.js 13 Pages Router, React 18, Tailwind CSS 3, Node's built-in test runner, Next.js Image.

## Global Constraints

- Preserve `/lab`, the existing navigation item, light/dark modes, and the zinc/teal site theme.
- Use large stable image frames, minimal chrome, no masonry, no flashy animation, and no portfolio-style project cards.
- Future entries require only date, title, photos, caption, and optional tags.
- Use local placeholders now, with stable paths that can be replaced by real photographs later.
- Do not commit; propose a Conventional Commit message at handoff.
